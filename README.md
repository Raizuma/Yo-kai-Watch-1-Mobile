# Yo-kai Watch 1 Mobile – Deutscher Fan-Patch

Ein inoffizieller deutscher Fan-Patch für **Yo-kai Watch 1 Smartphone**.

## Über das Projekt

Dieses Projekt übersetzt die Smartphone-Version von **Yo-kai Watch 1** vollständig ins Deutsche. Ziel ist es, die originale deutsche Lokalisierung möglichst originalgetreu auf die Mobile-Version zu bringen.

## Projektstatus

Der Patch befindet sich derzeit in der **geschlossenen Testphase**.

Die Übersetzung ist nahezu abgeschlossen. Aktuell werden nur noch kleinere Fehler behoben und letzte Anpassungen vorgenommen, bevor die erste öffentliche Version veröffentlicht wird.

## Installation

1. Lade den **EnmaPatcher** herunter:
https://github.com/hxgohxrr/Enma-Patcher/releases


2. Öffne den EnmaPatcher und gehe zu **Einstellungen**.

3. Trage unter **GitHub-Repo (Besitzer/Repo)** folgendes ein:

   ```
   Raizuma/Yo-kai-Watch-1-Mobile
   ```

4. Lasse den **Branch** auf:

   ```
   main
   ```

5. Speichere die Einstellungen und kehre zur Startseite zurück.

6. Der EnmaPatcher lädt nun automatisch die aktuellste Version des Patches direkt aus diesem Repository herunter.

## Fehler melden

Falls du Fehler findest oder Verbesserungsvorschläge hast, kannst du gerne ein Issue auf GitHub erstellen.

## Rechtlicher Hinweis

Dieses Projekt ist ein inoffizieller Fan-Patch und steht in keiner Verbindung zu LEVEL-5.

Es werden keine urheberrechtlich geschützten Spieldateien bereitgestellt. Für die Nutzung des Patches wird eine legal erworbene Version von **Yo-kai Watch 1 Smartphone** benötigt.
